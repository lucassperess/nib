# Security

Please report a vulnerability privately through GitHub's **Report a vulnerability** feature for this repository. If that option is unavailable, open an issue asking for a private contact channel without posting exploit details or personal data.

Do not include account cookies, complete private media URLs, local paths, or downloaded files in a public report. If you export diagnostics from Nib, review the file before sharing it.

Nib runs yt-dlp and FFmpeg locally. Keep the app and its extractor updated; only use links and account sessions you are authorized to access.
