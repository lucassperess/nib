# Privacidade da extensão Nib / Nib extension privacy

## Português

A extensão existe apenas para transferir ao Nib, no mesmo computador, os cookies de um serviço que você escolher: YouTube, Instagram ou X. Ela pede acesso ao serviço somente quando você clica em **Enviar sessão ao Nib**. O envio exige um código temporário gerado pelo aplicativo e usa `127.0.0.1`; não há servidor remoto do Nib envolvido. A extensão não guarda cookies, histórico de navegação ou o código após o envio. O Nib armazena a sessão criptografada no perfil do Windows e permite removê-la em **Configurações → Sessões privadas**. O site de origem poderá receber os cookies quando o Nib usar a sessão para uma tarefa sua. Use apenas contas que você controla.

## English

This extension only transfers cookies for a service you choose—YouTube, Instagram, or X—to Nib on the same computer. It requests site access only when you click **Send session to Nib**. Transfer requires a temporary code from the app and uses `127.0.0.1`; no remote Nib server is involved. The extension does not keep cookies, browsing history, or the code after transfer. Nib stores the session encrypted in your Windows profile and lets you remove it under **Settings → Private sessions**. The source site may receive the cookies when Nib uses the session for your task. Use only accounts you control.
